Showcase · Burrmill over relic 2079

    
One SQL statement, a number you can check.

    
Burrmill opens the sealed relic and runs each statement. Beside it, an independent Python script asks the RPC directly and sums with unbounded integers. It shares a provider with the Shadow, which is worth knowing. A refusal is a result: where a value does not fit DECIMAL(38,0), Burrmill says so instead of returning a smaller number.

What is checked

    
Two different claims, kept apart.

    
The Shadow checks its own input before journaling it. solo clean --files checks the published files afterwards, and anyone can repeat that. Neither establishes that this is the canonical chain.

Open questions

    
What this run cannot settle by itself.

    

      

        
The pact has no detached start.

        
RFC-0001 chains every relic to its predecessor, back to genesis, and relic 2079 has none. A drafted amendment adds detached_pact_start: a flag inside the manifest hash, valid only on the first relic of an unanchored run, which solo clean reports as an anchor not established. Until it is ruled on, 2079 is journaled and not sealed.

        
amendment drafted, awaiting a ruling

      

      

        
The fixtures found an era1 bug.

        
The shared decoder asked whether a typed envelope was an RLP list, which reads its type byte as a one-byte string. Every type 1 and 2 transaction was refused, so era1 relics after Berlin could not have been sealed. Fixed on the branch.

        
fixed, pete/rpc-journal
